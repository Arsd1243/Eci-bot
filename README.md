# Eco-bot
Bot ecológico, el nombre es Eco-bot (no Eci-bot como se llama el repositorio, fue un error mio), encontrarás el código en una sola carpeta, puede brindarte una información básica pero eficiente. El prefijo es "!", seguido del comando a querer utilizar, si no sabes que comandos se usan, te recomiendo empezar con este "!ayuda" y te enlistará todos los comandos disponibles por el momento. El bot se encarga de: mostrarte un consejo ecológico aleatorio; te dice si el objeto se recicla o no; explica qué tipo de información ofrece el bot y muestra lal ista de comandos (mencionado anteriormente).
